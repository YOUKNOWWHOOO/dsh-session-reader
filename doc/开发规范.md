# session-reader 开发规范

本文件规定 session-reader 技能（`SKILL.md` + `scripts\` + `tests\` + `doc\` + 工程文件）开发与维护必须遵守的要求与约束。

## 定位与范围

- 本技能只读 dsh 会话历史（`~\.dsh\sessions` 与 `~\.dsh\storages`）；除写入 `--output-dir` 指定目录内的输出文件外，禁止写入、删除或修改 dsh 主目录内的任何内容。
- 运行时禁止启动 dsh、禁止联网、禁止产生模型调用、禁止读取凭据文件（`.credentials.yaml`、`.env`、含凭据的 profile 补丁）。
- 技能范围限于 `SKILL.md`、`scripts\`、`tests\`、`doc\` 与工程文件（`package.json`、`tsconfig.json`、`biome.json`、`.markdownlint.jsonc`、`.markdownlintignore`、`.gitignore`）。

## 语言与运行

- 脚本语言为 TypeScript（ESM，`.ts`），由 Node（v26 线）原生类型剥离直接执行；禁止引入构建步骤或提交编译产物。
- 仅使用可擦除语法：禁止 `enum`、`namespace`、参数属性、装饰器。
- 相对导入必须带 `.ts` 扩展名；类型导入必须使用 `import type`。
- 除官方格式库外零运行时第三方依赖；官方库必须经 `createRequire` 锚点解析后动态 `import()` 加载，禁止静态导入外部包（tsc 无法解析）。
- 导出函数必须显式标注参数与返回类型；禁止 `any` 与非空断言 `!`。
- 错误处理使用 Result 风格（`{success:true,data}|{success:false,error}`）；禁止空 catch；禁止 catch 后静默切换备选路径。
- 文件编码 UTF-8 无 BOM；换行 LF。

## 数据契约

- 会话日志只读；逻辑解码的唯一实现为官方 `@deepseek-ai/dsh-session-format-catalog` 公开 API（`readHeader`/`createRestore`/`decodeRow`/`finish`），全部调用收敛于 `scripts\lib\decode.ts`。
- 物理层按官方算法（结构性帧扫描）自研；禁止依赖未文档化细节。
- 解码选项固定为 `{ recovery: 'recoverable', validation: 'transformed' }`。
- 强制一致性校验：喂入 `decodeRow` 的事件行数必须等于 `finish()` 结果的事件数；不一致按数据错误处理（退出 3）。
- `readHeader` 分类为 `malformed`/`unsupported` 时必须显式失败；禁止回退或猜测。
- 坏行与尾部截断必须记入 anomalies 并在输出中显式标注；禁止静默丢弃。
- 列表/统计元数据以 projcache 为唯一来源，使用前校验其 `version`（必须恰为当前格式版本 7）与 identity 可比字段（formatVersion/createdAt/cwd/isSeeded，四项须全等）；校验失败或记录缺失必须标注"元数据不可用"并给出原因，禁止静默空值与跨源混用。
- `show`/`search` 直接解码日志，不依赖 projcache；工作区标题仅来自 `workspace.json`。
- `search --scope` 三档为单调包含关系且 `all` 为穷尽档：`text`=用户/助手正文；`tools`=另含工具参数与结果；`all`=另含推理/系统/压缩/命令/标题请求/web 请求/交付物/待办/代理信箱 ＋ **每个事件的完整 JSON 载荷**（标签取事件类型）。`all` 档的穷尽性是"检索 0 命中 ⇒ 不存在"这一推断成立的前提，禁止在 `all` 档下遗漏任何事件记录。默认保持 `text`（改变默认会改变所有默认调用的命中集）。命中总数按**检索单元**计数：同一段文本在 `all` 档可能同时命中按字段枚举的单元与整条事件载荷单元而被计两次，因此 `tools`/`all` 的计数大于文本出现次数；`totalIsExact` 仅表示该数未被 `--limit` 截断，不得据此宣称"文本出现次数"。

## CLI 契约

- 子命令固定为 `list`、`show`、`search`、`stats`、`check`；每个命令只接受自己的选项集，未知或不适用选项退出 2。
- 全局选项固定为 `--dsh-home`、`--lib-root`、`--output-dir`、`--name`、`--format`、`-h/--help`。
- `--format` 取值：`md`（默认）/`json`；`show` 额外支持 `jsonl`。呈现类开关（`--role`、`--thinking`、`--tools`、`--events`、`--headers`、`--truncate`、`--turn`、`--seq`、`--head`、`--tail`、`--probe`）仅 md；`--summary` 与 `--subagents`（内容范围开关）在 jsonl 禁止（违者退出 2）。`--head` 与 `--tail` 互斥；`--summary` 与 `--turn`/`--seq`/`--head`/`--tail` 互斥；`--probe` 与 `--subagents` 互斥（`--probe` **允许**与其它呈现类开关同用：它按同一组开关渲染副本并据实报告字节数，这正是"量出带这些选项的导出有多大"的用法）。旧取值 `text` 已移除，传入即退出 2。
- 取值语义：`--limit`、`--head`、`--tail` 的 `0` 表示不限；`--truncate` 的 `0` 表示不截断；`--context` 默认 60 且按码点取命中两侧窗口；`--turn` 最小 1、`--seq` 最小 0，区间含端点。
- 解析语义：选项不可重复（重复即退出 2）；开关不接受值（`--full=1` 退出 2）；支持 `--opt=value` 内联写法；位置参数不终止选项解析；不存在 POSIX 合并短选项；`-h`/`--help` 出现在终止符之前即短路为帮助，帮助写 stdout、退出 0、不要求 `--output-dir`。
- `--name` 只接受单一路径段：ASCII 字母、数字、`_`、`-`，加 CJK 统一表意文字基本区、扩展 A 与兼容区（不含扩展 B 及以后，如 `𠮷`）；长度 1-64（按 UTF-16 单元）；拒绝 `.`、路径分隔符、空白、控制字符与 Windows 保留设备名（`CON`、`PRN`、`AUX`、`NUL`、`COM1`-`COM9`、`LPT1`-`LPT9`，共 22 个）。理由：产物路径必须恒为 `--output-dir` 的直接子文件。
- 支持 `--` 选项终止符：其后所有 token（含以 `-` 开头者）一律作为位置参数；帮助识别只扫描终止符之前的 token。必需选项必须写在终止符之前——`--output-dir` 落在终止符之后会被当作位置参数而报 `位置参数过多`。帮助文本与 `SKILL.md` 必须同步登记。
- 范围过滤（`--workspace`、`--since`、`--until`、`--origin`）仅作用于 `list`/`search` 与 `stats` 的全局聚合；`stats <目标>` 提供目标时与范围过滤同用即拒绝（退出 2），不做静默忽略。`search --session <标识>` 与 `search --exclude-session <标识>` 复用 `show` 目标语法，作用为该会话及其 `parentSession` 递归子树的正选与反选，与范围过滤以交集生效；两者可同时给出，此时对同一子树取交集（通常得空集）；目标不存在时按目标解析三态报错（不静默忽略）。
- 过滤项的失败与匹配语义必须区分：`--workspace` 为路径归一化全等（`\` 转 `/`、去尾部 `/`、转小写）或工作区标题全等，无任何匹配时按 `target-missing` 退出 1；`--title` 为标题子串匹配、不区分大小写，标题为 null 或元数据不可用时该会话落选，无匹配时正常返回空结果、退出 0；`--origin` 的唯一判据是 header 的 `origin` 为 `subagent`。
- `search` 与 `stats` 恒包含空会话（`includeBlank: true`），`list` 默认隐藏 `blank` 为真者且只提供 `--include-blank`；`blank` 为 null（元数据不可用）不隐藏。
- 选项表是解析、校验与帮助的单一真值源；修改 CLI 必须同步更新选项表、帮助文本、`SKILL.md` 与测试。
- 退出码：`0` 成功（含 0 命中等空结果、`--help`、`check` 无异常）；`1` 目标不存在（含前缀歧义、`--workspace` 无匹配、`--dsh-home` 不存在、`sessions` 缺失）；`2` 参数错误（含未给 `--name` 时目标已存在、前缀短于 8 字符）；`3` 数据/IO 错误（含官方格式库加载失败，其分类为 `内部错误`）。`check` 发现异常时**先落盘并打印两行 stdout、stderr 为空，再以 3 结束**，因此非 0 退出不蕴含没有产物。
- stderr 只输出单行 `错误: <分类>`；分类全集：`参数无效`、`目标不存在`、`输出文件已存在`、`输出目录创建失败`、`输出写入失败`、`输出移动失败`、`数据不可读`、`内部错误`。分类后可附一段括号说明：歧义目标附候选数（形如 `错误: 目标不存在（候选 N 个）`）；**仅组合冲突分支**附冲突选项名与**可执行的合法替代写法**（形如 `去掉 --events，或把 --format 改为 md`），替代写法用分号分隔、禁止嵌套括号；解析层与取值诊断分支只回显选项名/子命令位 token 或合法格式，不提供替代写法。说明来源固定为三处：`validateCommandOptions` 的组合约束、解析层 `parseCommandLine` 的错误文本（只回显选项名或子命令位 token，不回显选项值）、以及固定模板的取值诊断（`--name`/`--turn`/`--seq`/`--since`/`--until`，只含选项名与合法格式，不含调用方数据）。错误行不得包含会话内容、会话 ID、用户名与 dsh 数据路径；数据层 `StoreError.detail`（含会话目录名与绝对路径）禁止外显，仅 `argument-invalid` 的固定模板 detail 可由 `mapStoreError` 透传。
- 目标解析必须三态可区分（P7 根因修复）：唯一匹配且可读 → 执行；多个匹配（含 `session-` 前缀归一化后的精确歧义与一般前缀歧义）→ `ambiguous`/退出 1；无匹配但存在因 header 不可读而被跳过的会话目录其标识前缀匹配 → `data-unreadable`/退出 3；其余无匹配 → `target-missing`/退出 1。被跳过目录的匹配按目录名判定（header 不可读时无从取得逻辑 id）。
- 时间显示为含时区偏移的 ISO 8601 本地时间（秒级、无毫秒）；JSON 中的时间字段为原始毫秒数。过滤参数按 UTC 解析：接受毫秒数或严格 ISO，纯数字串按毫秒解释，无时区后缀按 UTC，日历或偏移越界即拒绝。
- 过滤基准是会话的"有效最近活动时间" = projcache 的 `lastPromptAt`，缺失时回落 header `createdAt`；比较双端含端点，不校验两者先后。它与产物中的 `事件时间范围`（来自事件自带 `time`）不是同一口径，两者不得互相替代。
- 空值在文本中显示 `-`，在 JSON 中为 `null`。

## 覆盖声明契约

- 每个命令的产物（md 与 json）必须让调用方判定"扫到了什么、纳入了什么、排除了什么、是否被截断"，字段与文案固定（`--probe` 产物按「规模探测」条款只含头部 KV 与两项，不含覆盖声明）：
  - md：`扫描会话 N 个；纳入 M 个；排除 K 个`，随后对每个被排除会话输出一行 `排除会话：<完整 id>（<原因>）`；`show --subagents` 另对每个归属未知的跳过项输出一行 `归属未知：<id>（<原因>）`；`search` 与 `stats` 另输出 `扫描明细：解码日志 X 份；读到事件 Y 个；解码失败 Z 份；帧解压失败 W 帧` 与 `事件时间范围：<下界> ~ <上界>`；`search` 另输出 `检索范围：<scope>（<覆盖面描述>）；命中总数 X 为精确值`、`命中总数：X`（被截断时追加 `；已截断显示 N 条（--limit 0 显示全部）`）与 `## 每会话命中分布` 表格及其固定提示行；`show` 在范围选择生效时按块输出 `筛选：…；显示 X 条时间线条目（区间内事件 Y 个，共 Z 个事件）`。
  - json：`coverage: { scannedCount, includedCount, excluded: [{ id, reason }], unattributable?: [{ id, reason }] }`，其中 `unattributable` 仅 `show --subagents` 出现；`search`/`stats` 另含 `scan: { logsDecoded, eventsRead, decodeFailures, frameFailures, observedFrom, observedTo }`；`search` 另含 `scope`、`totalIsExact`、`distribution: [{ sessionId, type, title, hits }]`。
- `N = M + K` 恒成立。`M` 是本次作用域内进入结论的会话数（范围过滤后的会话数减去其中解码失败者）；`K` 是本次无法纳入的会话数，来源为发现阶段 header 不可读的全库会话与作用域内解码失败者。**同一会话不得同时计入 `M` 与 `K`。** `unattributable` 单独计数，不计入 `N`/`M`/`K`。
- 被排除的会话必须逐条列出，禁止合并为计数或静默丢弃。单个会话 header 不可读或解码失败不得使聚合命令（`list`/`search`/`stats`）整体失败——这会让一份损坏日志永久阻断对其余会话的浏览与检索；改为跳过并声明。单目标命令（`show`、`stats <目标>`）在目标自身不可读时显式失败（退出 3）；`show --subagents` 在任一子代理解码失败时同样显式失败，而 header 不可读的子代理无从判定归属，必须列入 `unattributable` 而非静默丢弃。
- 覆盖声明描述"本次检查了哪些会话"，与 `--limit` 无关（`--limit` 只决定产物列出多少条，由命令级摘要与产物行数表达）。因此 `includedCount` 恒为"进入本次结论的会话数"：解码失败的会话只出现在 `excluded` 中，不得计入 `includedCount`。
- 扫描摘要的语义边界：`logsDecoded` 是成功解码的日志份数，`eventsRead` 是解码得到的事件总数，`decodeFailures` 是解码失败的日志份数（逐条在 `coverage.excluded` 中），`frameFailures` 是帧解压失败的帧数累计。`observedFrom`/`observedTo` 来自**事件自带的 `time` 字段**，禁止改用会话的"最近活动时间"（后者来自 projcache，语义不同）。
- `search` 的 `--limit` 只限制 `hits` 收集上限，`totalHits` 对纳入会话全量计数且不做提前终止；`totalIsExact` 恒为 `true`，其证据链为：全量计数 ＋ `scope=all` 覆盖任意事件记录的完整载荷 ＋ 未纳入会话逐条列入 `coverage.excluded`。该数的计量单位是检索单元内的匹配次数，不是文本出现次数。
- 命中分布（`distribution`）必须包含**0 命中的纳入会话**，按命中数降序、同数按会话 id 升序；其存在理由是让调用方把"自己的会话与子代理会话的命中"从结论中剔除（检索在全库上做，调查笔记与复述过的错误串都会被命中）。表格为空时不得输出该区块（空表会触发 MD055）。
- 调用方剔除自身语料的两种手段必须同时提供：产物中的逐会话分布（人工判断）与 `--exclude-session <标识>`（自动化，语义为该会话及其 `parentSession` 递归子树的反选）。

## 输出策略

- 所有命令必须显式指定 `--output-dir`（无默认值）；缺省退出 2；工具对目录位置零假定、不校验，不限制其是否位于 dsh 主目录内（唯一要求是调用方显式指定）。
- 目录不存在时创建；创建、写入或移动失败退出 3。
- 文件名：未指定 `--name` 时为 `session-reader-<命令>-<UTC 时间戳>-<随机 6 位>.<ext>`（md→md、json→json、jsonl→jsonl），指定 `--name` 时为 `<name>.<ext>`。
- 未指定 `--name` 时目标文件必须不存在；已存在时拒绝且不得改动原文件。实现为先 `existsSync` 检查、再写唯一临时文件、最后同卷 `renameSync`；"绝不覆盖"由命名唯一性（UTC 毫秒时间戳 + 随机 6 位后缀，碰撞概率 36⁻⁶/毫秒）消解，存在性检查与 rename 之间的竞争窗口在命中"同毫秒 + 同后缀"前不可触发（不改代码）。
- 指定 `--name` 时允许原子替换：Windows 的 `renameSync` 走 `MOVEFILE_REPLACE_EXISTING`，任何时刻目标文件要么是旧内容、要么是新内容；覆盖范围严格限于 `<output-dir>/<name>.<ext>`。
- 先写唯一临时文件，关闭后同卷原子移动；失败时必须清理临时文件。临时文件恒为 `.<产物文件名>.<随机 6 位>.tmp`（与目标同目录以保证同卷）。
- 输出编码固定 UTF-8 无 BOM、LF、末尾恰一个换行。
- stdout 固定两行：`完整输出已保存到: <绝对路径>` 与 `<摘要>；输出文件共 N 行`；N 必须等于输出文件实际行数；终端不显示会话正文。
- md 输出必须真实通过全局 markdownlint 基线（技能根 `.markdownlint.jsonc` 与全局基线逐条一致，只允许更严格）：禁止文件内豁免注释、禁止配置放宽、调用方无需排除输出目录；生成规则见下节「md 输出格式契约」。

## md 输出格式契约

md 渲染遵循 lint-safe 规则（f2 lint 合规 spike 定稿 R1–R5）；实现与测试的单一真值源为 `scripts\lib\render-core.ts`（载体与工具）、`render-md.ts`（聚合命令 md）、`render-show-md.ts`（show 的 md）、`render-json.ts`（JSON/JSONL）、`render-summary.ts`（命令级摘要文案），及其单元测试与 lint 门禁：

- R1 骨架与空白纪律：文件为 UTF-8 无 BOM、LF、末尾恰一个换行；标题/列表/表格/围栏/段落之间恰一个空行；标题仅用 ATX 且行首书写、文本取固定词表、无尾标点、同级唯一；加粗只作行内前缀（标签行恒以 `：` 收尾，禁止独立成段）；列表只用短横线标记且标记后恰一个空格；表格首尾管道齐全、列数一致、单元格间距统一、前后空行；围栏固定为反引号 + 语言 `text`，反引号长度 = 载荷最长连续反引号串 + 1 且不小于 3。
- R2 载体隔离：多行文本只用围栏代码块承载；单行文本只用行内代码跨度承载（反引号长度动态；内容以反引号开头或结尾时双边加一个空格内边距）；表格单元格值先经行内载体再把 `|` 转义为 `\|`；禁止任何会话来源文本以裸文本进入结构。
- R3 极小归一化（唯一允许的内容改动）：CRLF 与孤立 CR → LF；制表符 → 4 空格（MD010）；行内载体首尾空白去除（MD038；全空白值保留原样）；行内载体与轮次大纲把内嵌换行折叠为空格（单行载体的前提，改变字符序列，因此必须显式登记）；当且仅当围栏载荷每个非空行都匹配 `^\s*\$\s+` 时在载荷末尾追加一行单个空格（MD014；原文各行逐字不变）。CR 归一化的必要性：会话正文可能含 CR 字节（实测 907 个 lint 门禁产物中 5 个因正文含 CR 而混入 CR 字节），markdownlint 无规则可判 CR，因此它是契约层面的静默破坏而非 lint 问题。
- R4 边界：空值显示 `-`；控制字符、RTL/组合字符、零宽字符、NUL 在代码载体内原样保留；超长单行不截断（MD013 关闭）。
- R5 参考实现：规则逐字定义与载体对照实验见 `.tmp` 侧 f2 spike 产物（`render-rules.mjs`）；本技能由 `scripts\lib\render-core.ts` 落地，行为由 `tests\render-core.test.ts`、`render-list.test.ts`、`render-show-md.test.ts`、`render-show-json.test.ts`、`render-search-stats-check.test.ts`、`render-boundary.test.ts`（规则单元测试）与 `tests\lint-matrix.ts`（全组合穷尽门禁）双重覆盖。
- 会话标识输出：列表、命中行与摘要行一律输出**完整会话 id**，禁止输出截断值——显示值必须与可传值同源，截断值必然引入"显示≠可用"这一整类缺陷。
- 文本载体截断：所有文本载体（用户/助手正文、推理、工具参数与结果、系统消息、`--events` 事件载荷、轮次大纲）共用同一 `--truncate` 口径，按码点截断并追加 `…`，`0` 即不截断，禁止为任何载体另设固定上限。唯一例外是每会话命中分布表格的标题列（按码点截断 40，见下条）。
- 范围选择的呈现语义：`--turn`/`--seq` 筛选事件序列（交集、含端点）且作用于每个块（子代理各自的 turn 与 seq 按自身事件流计），`--head`/`--tail` 作用于筛选后的条目序列且只作用于根块；子代理块因此只受 `--turn`/`--seq` 影响。筛选生效时每个受影响的块各输出一条筛选说明行，给出该块显示条目数、该块区间内事件数与该块事件总数。
- 规模探测（`--probe`）：产物只含头部 KV 块与 `- 预计字节数：N`、`- 消息数：X 用户 / Y 助手`，不含任何会话正文。`N` 必须等于"以同一组选项渲染完整导出"的 UTF-8 字节数——实现方式就是真的渲染一份副本并测量，禁止用估算公式（估算要重复渲染规则，必然与真实产出漂移，而漂移会让调用方的容量判断失效）。探测只作用于主会话块。
- 每会话命中分布表格的标题列按码点截断到固定上限，避免单行无界增长。
- 子代理块层级：所有子代理块固定 H2（`## 子代理 <路径编号>`）、子内容固定 H3；嵌套关系只由路径编号表达，标题层级不随深度递进（保持实现不变；按标题层级解析的读者以路径编号判父子）。
- 技能目录的 lint 边界：技能自带 `node_modules`（开发依赖），从技能目录运行 lint 时由技能根 `.markdownlintignore` 排除；从仓库根做全量扫描时由仓库根 `.markdownlintignore` 排除（该文件同时排除 `profiles/`、`tmp/`、`.tmp/` 等第三方或临时内容）。技能自有 `.md` 文件必须全部纳入检查，禁止借 ignore 排除自有内容。

## 兼容性要求

- 官方库 API 变化只允许修改 `decode.ts` 单点适配；`--lib-root` 必须始终可覆盖默认锚点。
- 默认锚点为 `<dsh-home>\profiles\node_modules`；解析失败必须显式报错退出 3。
- 格式版本分类交给官方库；代码不得硬编码 v3 之外的格式结构假设。
- dsh 升级后必须重跑全部测试与真实数据只读抽查，并记录官方库版本。

## 安全要求

- 禁止读取 `.credentials.yaml`、`.env`、含凭据的 profile 补丁文件。
- 输出、日志与错误不得包含凭据值。
- 文件操作保持最小范围：只读会话、projcache 与 workspace 所需文件；只写 `--output-dir` 指定目录。
- 不得修改 dsh 数据；不得建立任何形式的缓存。

## 测试要求

- 测试先行、负面路径必测；测试框架固定为 `node:test`。
- 覆盖率要求：行覆盖率 ≥80%、分支覆盖率 ≥85%（`node --test --experimental-test-coverage` 实测）。
- 夹具运行时生成于 `tests\.tmp\` 并自清理；夹具不得写入仓库其它位置。
- CLI 集成测试必须使用真实官方库与合成 DSH_HOME，断言 stdout 两行契约、输出行数与摘要一致、退出码与错误分类正确；必须覆盖"显示值即可传值"（`list` 产物中的 id 直接交给 `show` 成功）、`--name` 连续覆盖、范围选择（`--turn`/`--seq`/`--head`/`--tail`）、`search --session`、以及容错声明（排除项逐条出现）。
- md 渲染规则必须有不依赖 markdownlint 的单元测试（围栏动态长度、行内跨度、四条归一化、截断口径、结构纪律）。
- 必须维护全组合 lint 门禁，入口为 `tests\lint-matrix.ts`（CLI 解析、逐组合执行、确定性复跑与汇总），其余职责分列 `tests\matrix-paths.ts`（共享锚点）、`matrix-fixtures.ts`（敌意内容集与合成 DSH_HOME）、`matrix-cases.ts` 与 `matrix-cases-query.ts`（组合词汇表与各命令组合）、`matrix-assert.ts`（结构白名单、json/jsonl 回归与 markdownlint 调用）：命令×参数组合（开关全交叉、枚举与值选项 2 路覆盖并补边界）+ 敌意字段注入夹具 + 真实只读会话；全部 md 产物统一经 `npx --no-install markdownlint-cli --config <技能根 .markdownlint.jsonc>` 断言退出 0 且无输出；同批断言结构白名单（标题词表/围栏闭合/末尾换行/空行纪律）、json/jsonl 回归、确定性与错误路径。
- 技能目录自身的 lint 命令为 `npx markdownlint-cli --config .markdownlint.jsonc .`；`.markdownlintignore` 只排除非交付目录（开发依赖 `node_modules/` 与测试临时夹 `tests/.tmp/`），技能自有 .md 文件（含本规范）全部纳入检查，禁止借 ignore 排除自有内容。
- SKIP 计为 FAIL；任何告警、报错或失败必须逐项记录。

## 维护要求

- 修改脚本时必须同步：`SKILL.md`、本规范、测试与夹具；并运行完整校验链（`npx biome ci .`、`npx tsc --noEmit`、`node --test`、各命令 `--help`、技能目录 `npx markdownlint-cli --config .markdownlint.jsonc .`、全组合 lint 门禁 `node tests/lint-matrix.ts --workdir <目录>`）。
- CLI 必须保持默认组合可用性：除 `--output-dir`（必填）与命令目标外，所有选项必须有默认值；默认组合的可见性/格式/截断/输出行为属于对外契约，变更必须同步 `SKILL.md` 并过全套校验。
- 校验链全部通过方可提交；校验未通过时禁止以任何理由跳过、降级或放宽判定。
- 官方库版本升级必须记录在验证记录与提交信息中。
- 禁止保留已废弃代码路径与向后兼容垫片；不使用的代码必须删除。
- 源码与测试文件不得超过 1200 行（与全局代码编写规范一致），建议 200-600 行；拆分必须保持行为、导出签名与文案不变，并同步更新本规范、`SKILL.md` 与测试中的所有引用路径。
