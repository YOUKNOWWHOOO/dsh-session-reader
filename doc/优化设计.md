# session-reader 优化设计（v2，面向 agent 可用性）

本文件是 `session-reader` 技能下一版（下称 v2）的**设计与契约**。它取代 `doc/优化待办.md` 中的"期望行为"表述：待办给出问题与验收标准，本文件给出唯一确定的目标契约与实现方案。

阅读顺序：先读「现状核实」，再读「契约增量」，最后读「逐条落地」。任何与现有 `SKILL.md`、`doc/开发规范.md` 冲突之处，以本文件为准（落地时同步修订这两份文件，不留双重真值源）。

每条 P 项都经过本机实测复核（命令 + 原始输出），结论与待办描述存在差异的部分已逐条标注。

## 2 目标与边界

### 2.1 目标

1. **显示值即可传值**：`list` 输出的会话标识可直接作为 `show`/`stats`/`check`/`search --session` 的目标参数使用，退出 0。
1. **边界可自证**：每次输出在产物内以固定字段给出"检索/统计覆盖了哪些会话、排除了哪些会话及原因、结果是否被截断、命中总数是否为精确值"，使调用方无需读源码即可判断结论强度。
1. **产物路径可控可复用**：调用方可指定产物 basename，并可覆盖自己指定过的同名产物。
1. **范围选择**：可只读某会话的 turn/seq 区间或首尾若干条，可只检索某会话（含其子代理子树），且不产生整份导出。
1. **错误可区分可自诊**：目标不存在、目标歧义、目标存在但不可读、参数错误四类互不混淆；参数错误给出合法替代写法。
1. **全称断言的证据充分性**：在 `--scope all` 下，日志中任意事件记录的任意字符串都可被检索到；检索 0 命中不再需要附带"未索引"的免责声明。

### 2.2 非目标（明确不做）

- 不引入缓存（任何形式）。
- 不引入重量级依赖；运行时仍为零第三方依赖（仅官方格式库经 `createRequire` 动态加载）。
- 不做向后兼容垫片：被取代的实现与字段直接删除。
- 不新增子命令；退出码体系仍为 0/1/2/3。

## 3 契约增量（对外）

### 3.1 新增选项

新增 5 个选项，全部登记进 `scripts/session-reader.ts` 的选项表（解析、校验、帮助的单一真值源）。

| 选项 | 适用命令 | 取值 | 默认 | 语义 |
| --- | --- | --- | --- | --- |
| `--name <basename>` | 全部 | 单一路径段，见 §3.3 | 无（回落时间戳命名） | 指定产物 basename（不含扩展名） |
| `--turn <A-B\|A>` | `show` | 正整数或 `A-B`（`A≥1`、`B≥A`） | 无 | 只呈现指定 turn 区间的事件 |
| `--seq <A-B\|A>` | `show` | 非负整数或 `A-B`（`A≥0`、`B≥A`） | 无 | 只呈现指定 seq 区间的事件 |
| `--head <N>` | `show` | 非负整数 | 无 | 只呈现筛选结果的首 N 条 |
| `--tail <N>` | `show` | 非负整数 | 无 | 只呈现筛选结果的末 N 条 |
| `--session <标识>` | `search` | 与 `show` 目标同语法 | 无 | 只检索该会话及其子代理子树 |

### 3.2 选项组合约束（新增，违者退出 2）

在现有约束（`--format json|jsonl` 禁呈现类开关；`--format jsonl` 另禁 `--summary`/`--subagents`；`stats <目标>` 禁范围过滤）之上新增：

1. `--turn`/`--seq`/`--head`/`--tail` 属呈现类开关，与 `--format json|jsonl` 互斥（沿用既有规则，无需新分支）。
1. `--head` 与 `--tail` 互斥。
1. `--turn`、`--seq` 可同时使用（交集语义）；`--head`/`--tail` 可与 `--turn`/`--seq` 同时使用（对交集结果取首尾）。
1. `--turn`/`--seq`/`--head`/`--tail` 与 `--summary` 同时使用即拒绝：`--summary` 呈现的是整会话轮次大纲，区间选择对其无意义，静默忽略会掩盖调用方意图。

### 3.3 `--name` 取值约束

- 合法字符集：ASCII 字母、数字、`_`、`-`，以及 CJK 统一表意文字区间 `U+4E00-U+9FFF`、`U+3400-U+4DBF`、`U+F900-U+FAFF`。
- 显式拒绝：`.`（避免与扩展名产生歧义）、`/`、`\`、`:`、`*`、`?`、`"`、`<`、`>`、`|`、空格与其它空白、全部控制字符。
- 显式拒绝（不区分大小写）：`CON`、`PRN`、`AUX`、`NUL`、`COM1`-`COM9`、`LPT1`-`LPT9`。
- 长度：1-64 字符。
- 产物名 = `<name>.<ext>`，扩展名仍由 `--format` 决定（md→`md`、json→`json`、jsonl→`jsonl`）；调用方无需也不得书写扩展名。

拒绝理由（防路径穿越与覆盖越界）：产物路径必须恒为 `--output-dir` 的直接子文件。若允许 `.`/分隔符，`--name ..\..\x` 或 `--name a.b` 会使"产物"落到输出目录之外或产生双重扩展名歧义，破坏"只写 `--output-dir` 指定目录"的既有安全约束。

### 3.4 产物写入语义

| 场景 | 目标文件 | 已存在时的行为 |
| --- | --- | --- |
| 未指定 `--name` | `session-reader-<命令>-<UTC 时间戳>-<随机 6 位>.<ext>` | 拒绝，退出 2（分类 `输出文件已存在`），不得改动原文件 |
| 指定 `--name` | `<name>.<ext>` | **原子替换**：先写唯一临时文件，关闭后同卷 `renameSync` 覆盖目标 |

原子替换由 `renameSync` 在 Windows 上的 `MOVEFILE_REPLACE_EXISTING` 语义保证（本机实测：`renameSync(tmp, existingTarget)` 成功且目标内容被替换、临时文件无残留）。覆盖范围严格限于调用方自己用 `--name` 指定的那一个路径（`<output-dir>/<name>.<ext>`），不涉及输出目录内其它文件。

临时文件命名恒为 `.<产物文件名>.<随机 6 位>.tmp`，位于同一目录（保证同卷），任何失败路径都必须删除临时文件。

### 3.5 stdout 契约（不变）

仍固定两行：`完整输出已保存到: <绝对路径>` 与 `<摘要>；输出文件共 N 行`。`N` 必须等于输出文件实际行数。

### 3.6 stderr 与退出码契约

分类全集不变（`参数无效`、`目标不存在`、`输出文件已存在`、`输出目录创建失败`、`输出写入失败`、`输出移动失败`、`数据不可读`、`内部错误`），括号说明的既有形态（候选数、冲突/缺失选项名、子命令位或选项位 token）不变。新增两条**明文规则**：

1. **目标解析的三态区分**（对应 P7）：解析 `show`/`stats`/`check` 目标时，
   - 有唯一匹配且可读 → 正常执行；
   - 有多个匹配（含 `session-` 前缀归一化后的精确歧义与一般前缀歧义）→ `错误: 目标不存在（候选 N 个）`，退出 1；
   - 无匹配，但存在**因 header 不可读而被跳过的会话目录**其标识前缀与给定值匹配 → `错误: 数据不可读`，退出 3；
   - 其余无匹配 → `错误: 目标不存在`，退出 1。
1. **参数错误必须给出合法替代写法**（对应 P8）：组合约束类错误（`validateCommandOptions` 产生的 detail 与解析层对互斥组合的拒绝）在括号说明中除冲突选项名外，必须给出可执行的替代写法。替代写法用分号与冲突描述分隔，禁止嵌套括号（stderr 已有一层分类括号，嵌套会破坏可读性与机器解析）。
   - 例：`错误: 参数无效（呈现类开关 --events 仅 md 可用；去掉 --events，或把 --format 改为 md）`
   - 例：`错误: 参数无效（--summary 不能与 --format jsonl 同时使用；去掉 --summary，或把 --format 改为 json）`
   - 例：`错误: 参数无效（--head 与 --tail 不能同时使用；只保留其中一个）`
   - 例：`错误: 参数无效（--summary 与 --turn 不能同时使用；去掉 --summary，或去掉 --turn）`
   - 例：`错误: 参数无效（单会话统计不接受范围过滤选项 --workspace；去掉 --workspace，或去掉会话目标改用全局聚合）`

stderr 仍不得包含会话内容、会话 ID、用户名与 dsh 数据路径。

### 3.7 `search --scope` 语义修订（对应 P3）

`--scope` 取值不变（`text|tools|all`），三档改为**单调包含**关系，且 `all` 为**穷尽**档：

| 取值 | 覆盖的文本单元 |
| --- | --- |
| `text` | `user/message` 正文、`assistant/message` 正文 |
| `tools` | `text` 全部 ＋ `tool/call` 的 arguments ＋ `tool/result` 的结果正文 |
| `all` | `tools` 全部 ＋ `assistant/message` 推理 ＋ `system/message` ＋ `compaction/summary`（summary 与 rawOutput）＋ `command/run`（name+args）＋ `command/done` ＋ `session/title-llm-request`（system+messages）＋ `web/deepseek-search-llm-request`（body）＋ `deliverables/presented` ＋ `todo/write`（todos）＋ `agent/inbox/spliced`（inserted 内容）＋ **每个事件记录的完整 JSON 序列化载荷（含 type/seq/time/data 全字段）** |

`all` 档的穷尽性由最后一项保证：任意事件记录的任意字符串必然出现在该字符串化载荷中。因此 `all` 档下"0 命中"可作为"不存在"的证据。

不把 `--scope all` 设为默认：默认 `text` 是既有契约，变更会改变所有默认调用的命中集；调用方需要穷尽性时显式选择 `all`，并由产物自证覆盖范围（§4）。

### 3.8 输出中的会话标识（对应 P1）

- `list` 的 md 表格与完整列表、`search` 的命中行、`show`/`stats`/`check` 的摘要行，一律输出**完整会话 id**。
- 删除 `shortId` 字段与 `SHORT_ID_LENGTH` 常量（`scripts/lib/store.ts` 与 `scripts/lib/render.ts` 各一份，属同一逻辑的双重定义）。理由是单一真值源：显示值与可传值必须同源，截断值必然引入"显示≠可用"这一整类缺陷。
- `show --subagents` 的子代理块标题 `## 子代理 <路径编号>` 保持路径编号语义不变（编号只表达层级，不表达标识符）。

### 3.9 范围选择的粒度与语义（对应 P5）

- `--turn A-B`：选中事件流中 `turn ∈ [A,B]` 的事件。事件的 turn 取自 `data.turn`；缺失时沿用"当前轮次"，由 `turn/start` 推进（`turn/start` 自身缺失 `data.turn` 时以计数 +1 推进），与 `computeTurns` 同口径；首个 `turn/start` 之前的事件不归属任何轮次，区间筛选时排除。
- `--seq A-B`：选中 `seq ∈ [A,B]` 的事件。
- 二者可同时使用，取交集。
- `--head N`/`--tail N`：对上述筛选后的**时间线条目序列**取首 N/末 N 条。`0` 与省略等价（不限）。按"条目"而非"事件"计数的理由：`turn/start`、`turn/end`、`session/title` 等事件不产生条目，按事件截取会出现"要 5 条却一条都没显示"。
- 逐节点语义：`--turn`/`--seq` 作用于每个节点（含子代理，各自以自身事件流计轮次）；`--head`/`--tail` 只作用于主会话块——子代理被 `--subagents` 显式要求导出，静默截掉它们会让"导出了全部子代理"这一预期落空。该不对称由 `SKILL.md` 显式声明。
- 筛选作用于呈现（md 时间线），不改变会话统计：头部 KV 块与"轮次大纲"的统计仍以整会话事件流为准（自证范围，不误导）。
- 一旦任一筛选生效，`show` 的 md 产物必须在时间线之后追加一行筛选说明，同时给出三个数字（最终显示条目数、区间内事件数、整会话事件数），形如：
  `筛选：turn 2-2；显示 2 条时间线条目（区间内事件 3 个，共 769 个事件）`
  未生效时不输出该行。

### 3.10 `search --session` 语义（对应 P5）

- 目标解析复用 `show` 目标的解析机制（完整 id／唯一前缀（≥8 字符，大小写不敏感，`session-` 可省）／`last`），解析失败按 §3.6 三态区分。
- 语义为**子树**：命中集合 = 该会话自身 ＋ 所有 `header.parentSession` 递归指向它的会话。
- 与 `--workspace`/`--since`/`--until`/`--origin` 的关系：以交集生效（先按范围过滤得到会话集合，再取 `--session` 子树与之相交），不静默忽略任一侧。
- 产物中被跳过的会话（`--session` 子树内 header 不可读者）必须计入 §4 的覆盖声明。

## 4 覆盖自证契约（对应 P2、P3、P7）

每个命令的产物（md 与 json）必须能让调用方判定下列四项，缺一不可：

| 项 | md 载体 | json 载体 | 取值来源 |
| --- | --- | --- | --- |
| 扫描到的会话总数 | `扫描会话 N 个` | `coverage.scannedCount` | 纳入数 ＋ 排除数 |
| 实际纳入的会话数 | `纳入 M 个` | `coverage.includedCount` | 本次结论实际使用的会话数（`list` 为写入产物的条目数，`search`/`stats` 为实际检索/聚合的视图数） |
| 被排除的会话及其原因 | 逐条 `排除会话：<完整 id>（<原因>）` | `coverage.excluded[] = {id, reason}` | `discoverReadableSessions.skipped` ＋ 解码阶段失败 |
| 结果是否被截断、命中总数是否为精确值 | `命中总数：N`、`检索范围：…；命中总数 N 为精确值` | `truncated`、`scope`、`totalIsExact` | `totalHits` 与显示条数比较；`totalIsExact` 恒为 `true` |

恒等式 `scannedCount = includedCount + excluded.length` 必须在所有命令与所有选项组合下成立，并由 lint 门禁逐组合断言。其语义边界：`scannedCount` 与 `includedCount` 都只统计**逻辑会话**（已成功读取 header 的会话目录），因此"枚举到但连 header 都读不出来的会话目录"不进入这个等式——它只在 `check`（不读 header 的枚举路径，全部纳入，因此恒有 `scannedCount = includedCount` 且排除为空）中体现。`list` 不读日志正文，因此不报告正文级解码失败；`search`/`stats` 读正文，因此把解码失败会话计入排除项。覆盖声明与 `--limit` 无关：`--limit` 只决定产物列出多少条（由命令级摘要的 `匹配 N 个，显示 M 个` 与产物行数表达），不改变"本次检查了哪些会话"。

`totalIsExact` 为 `true` 的依据：检索阶段对纳入会话**不做任何提前终止**（`totalHits` 全量计数，`--limit` 只作用于 `hits` 数组的收集上限），且 `all` 档保证任意事件记录的可检索性；被排除的会话不是"未确定"而是"显式排除并列出"。三项合起来使该布尔值有可验证的证据，而非声明式的安慰字段。`检索范围` 行同时给出该 scope 的覆盖面描述，使调用方能判断"0 命中"能否当作"不存在"（只有 `all` 可以）。

## 5 逐条落地（实现方案）

改动文件与职责，按依赖顺序：

### 5.1 `scripts/lib/paths.ts`

## 7 风险与缓解

| 风险 | 等级 | 缓解 |
| --- | --- | --- |
| `--scope all` 追加全事件载荷后命中数与耗时显著上升（本机 `search the --scope all` 预期从上万条量级进一步上升） | 中 | `hits` 仍受 `--limit` 上限约束（内存有界）；`totalHits` 仅整数累加；落地后以真实数据实测耗时并记录在验证记录中；不引入缓存 |
| 删除 `shortId` 破坏既有调用方的解析假设 | 中 | 该字段是缺陷来源（P1），删除属根因修复；在 `CHANGELOG` 与 `SKILL.md` 中显式标注为不兼容变更 |
| `list` md 表格因完整 id 变宽，影响可读性 | 低 | 表格单元格本身已用行内代码载体；lint 不受宽度影响（MD013 关闭） |
| `--name` 覆盖语义被误用导致调用方丢失自己上一次的产物 | 低 | 覆盖仅发生在调用方显式给出 `--name` 时；未给出时仍拒绝覆盖；`SKILL.md` 明确"覆盖即丢失上一次内容" |
| `--turn`/`--seq` 筛选后 KV 块统计仍是整会话，可能被误读为筛选范围统计 | 低 | 追加筛选说明行显式给出"显示 X 条 / 共 Y 个事件" |
| 容错列表（跳过不可读会话）使"漏读"变得隐蔽 | 中 | §4 强制逐条列出被排除会话及其原因；`list`/`stats`/`search` 三者都必须输出 |
| 错误文案变更使既有自动化调用方的字符串匹配失效 | 低 | 退出码体系不变（分类不变），仅括号说明变长；`SKILL.md` 声明"分类稳定、说明可能扩展，调用方只应依赖分类" |
